# MotionHub 성장 시스템 (Gamification) 기획·설계서

> **⚠️ 이 문서는 구버전입니다.**  
> **최신 MVP 설계:** [`motionhub-growth-system-mvp-design.md`](./motionhub-growth-system-mvp-design.md)

## 변경 요약 (v1 → MVP Beta v2)

| 항목 | 구버전 | MVP v2 |
|------|--------|--------|
| 경험치 | Score (spendable + lifetime) | **Growth** (영구 누적만) |
| 꾸미기 재화 | Score 소비 | **Seed** (씨앗) |
| 전환 | Mile → Score | Mile → Growth, Mile → Seed |
| MVP UI | 성장 + 마을 일부 | **성장 탭 + 운동나무**만 |

전체 아키텍처·DB·UI·로드맵은 MVP 설계서를 참고하세요.
