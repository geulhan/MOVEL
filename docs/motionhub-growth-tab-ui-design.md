# MotionHub 성장 탭 UI/UX 설계 보고서

> **목적:** DB 구현 전 UI/UX 검증 · Beta MVP  
> **범위:** 회원 앱 「성장」 탭 3화면 + 에셋 가이드  
> **연계:** [`motionhub-growth-system-mvp-design.md`](./motionhub-growth-system-mvp-design.md)  
> **작성:** 2026-06-05 · 구현 금지 (설계·목업만)

---

## 0. 설계 목표

회원이 앱에 들어온 **첫 3초** 안에 다음을 이해해야 한다.

> **「내 운동나무를 키우는구나. 운동하면 성장한다.」**

### 0.1 하지 않을 것

| 금지 | 이유 |
|------|------|
| 고퀄 RPG UI | CRM 앱 신뢰도 훼손 |
| 복잡한 3D | 제작·성능·유지보수 부담 |
| 과도한 게임 HUD | 정보 과부하, 40대+ 회원 이탈 |
| 「성장치 구매」 느낌 | Pay-to-win 인상 |

### 0.2 레퍼런스 무드

| 참고 | 가져올 것 | 버릴 것 |
|------|-----------|---------|
| 스타듀밸리 | 따뜻한 파스텔, 잔디 배경, 성장 만족감 | PC 해상도 밀도 |
| 동물의숲 | 친근한 일러스트 톤, 작은 마을 암시 | 복잡한 커스터마이즈 UI |
| 포켓캠프 | 단순 카드·진행도 | 가챠·과금 UI |
| 초기 메이플 | 도트 캐릭터·나무 성장 연상 | HUD 밀도·스킬 트리 |

**한 줄 무드:** *「따뜻한 운동 일기장 + 작은 정원」*

## 1. 디자인 시스템 (성장 탭 전용)

### 1.1 기존 MotionHub 브랜드와의 관계

회원 앱 기본 토큰(`cream` `#F5F0E8`, `charcoal` `#1C1C1C`, `gold` `#C8B882`)은 **유지**한다.  
성장 탭만 **도트 레이어**를 얹는다 — 전체 앱을 게임 UI로 바꾸지 않는다.

```
┌─────────────────────────────────────┐
│  앱 크롬 (기존)     cream · charcoal  │
├─────────────────────────────────────┤
│  성장 탭 캔버스     도트 배경 레이어   │  ← 신규
│  + 기존 카드/타이포  혼합              │
└─────────────────────────────────────┘
```

### 1.2 성장 탭 컬러 확장

| 토큰 | HEX | 용도 |
|------|-----|------|
| `growth-grass` | `#7CB86A` | 잔디 배경 타일 |
| `growth-grass-light` | `#9DCE8E` | 잔디 하이라이트 |
| `growth-soil` | `#8B6914` | 흙·화분 베이스 |
| `growth-sky` | `#B8D4E8` | 상단 그라데이션 (선택) |
| `growth-pink` | `#F4A7B9` | 벚꽃 단계 포인트 |
| `growth-seed` | `#D4A574` | 씨앗·씨앗 재화 아이콘 |
| `growth-accent` | `#5A9E6F` | Progress fill (teal보다 부드러운 녹색) |
| `growth-mile` | `#C8B882` | 마일 (기존 gold 계승) |

### 1.3 타이포

| 용도 | 스펙 |
|------|------|
| 화면 제목 | 18px / Bold / charcoal |
| 성장치 대숫자 | 28px / Bold / tabular-nums |
| 재화 라벨 | 11px / Semibold / charcoal/55 |
| 재화 값 | 15px / Bold / tabular-nums |
| 본문·기록 | 14px / Regular |
| 캡션 | 12px / charcoal/50 |

**도트 영역**에는 시스템 폰트 대신 **픽셀 정렬** — `image-rendering: pixelated` + 정수 배수 스케일(×3, ×4).

### 1.4 도트 그리드 규격

| 에셋 | 원본 | 화면 표시 | 비고 |
|------|------|-----------|------|
| 나무 스프라이트 | 32×32 px | 128×128 (×4) | 단계별 1프레임 (MVP) |
| 배경 타일 | 16×16 | 64×64 (×4) | 잔디·흙 타일링 |
| 소품 (꽃·길) | 16×16 | 32~48px | 정원 힌트용 |
| 재화 아이콘 | 16×16 | 20×20 | 카드 내 |

**팔레트:** 16~24색 제한 (스타듀밸리식 제한 팔레트). 안티앨리어싱 **없음**.

## 2. 재화 표시 방식 (마일 · 성장치 · 씨앗)

### 2.1 원칙

| 재화 | 회원 인식 | UI 톤 |
|------|-----------|-------|
| **성장치** | 「내가 쌓은 운동 기록」 | 가장 크게, 녹색 계열 |
| **마일** | 「센터에서 쓰는 혜택」 | gold, 기존 REWARDS 연속성 |
| **씨앗** | 「나중에 꾸밀 재료」 | 작은 씨앗 도트 아이콘, 갈색·연두 |

### 2.2 상단 재화 바 (GrowthWalletStrip)

3열 **동일 높이 카드** — RPG 인벤토리가 아닌 **은행 앱 잔액** 느낌.

```
┌──────────┬──────────┬──────────┐
│ 🌱 성장치 │ ✦ 마일   │ · 씨앗   │
│  1,240   │  3,200   │   48     │
└──────────┴──────────┴──────────┘
```

| 요소 | 스펙 |
|------|------|
| 컨테이너 | `rounded-xl`, `bg-white/90`, `border border-gold/20`, 패딩 12px |
| 아이콘 | 16×16 도트, 라벨 왼쪽 |
| 숫자 | `tabular-nums`, 천 단위 콤마 |
| 성장치 열 | 좌측 1px `growth-accent` 보더 — 시각적 우선순위 |

**접근성:** 색만으로 구분하지 않음 — 라벨 텍스트 필수.

### 2.3 용어 노출

| 내부 키 | 회원 UI 문구 | 영문 노출 |
|---------|-------------|-----------|
| growth | 성장치 | Growth (탭명만, 본문은 한글) |
| mile | 마일 | M (숫자 뒤 `M` 선택 가능, 기존 REWARDS와 통일) |
| seed | 씨앗 | — |

## 3. 운동나무 단계별 도트 컨셉

### 3.1 단계 정의 (MVP)

| stage_key | min_growth | 한글명 | 도트 컨셉 |
|-----------|------------|--------|-----------|
| `none` | 0–9 | (시작 전) | 화분 + 맨흙, 작은 물방울 |
| `seed` | 10+ | 씨앗 | 화분 속 갈색 씨앗 1알 |
| `sprout` | 100+ | 새싹 | 두 잎 새싹, 줄기 얇음 |
| `small` | 500+ | 작은 나무 | 둥근 잎 3덩어리, 얇은 줄기 |
| `large` | 1,000+ | 큰 나무 | 넓은 캐노피, 굵은 줄기 |
| `sakura` | 3,000+ | 벚꽃나무 | 분홍 꽃잎 5~8px 도트 |

### 3.2 스프라이트 시트 (에셋 명세)

파일: `assets/growth/trees/tree_stages_32.png` (192×32, 6프레임)

```
[none][seed][sprout][small][large][sakura]
 32px  32px   32px    32px   32px   32px
```

**각 프레임 구성 (32×32 기준)**

| 단계 | 지면 | 주체 | 디테일 |
|------|------|------|--------|
| none | 흙 8px | 빈 화분 | 물뿌리개 옆 (선택) |
| seed | 흙 | 씨앗 4×4 | — |
| sprout | 흙+잔디 | 줄기 2px + 잎 2px×2 | — |
| small | 잔디 | 줄기 4px + 캐노피 16×12 | 작은 그림자 1px |
| large | 잔디 | 줄기 6px + 캐노피 22×16 | 새 1마리 (1px) |
| sakura | 잔디+꽃잎 2px | 줄기 6px + 분홍 캐노피 | 떨어지는 꽃잎 1~2 |

### 3.3 캔버스 배경 (나무 무대)

고정 크기 **280×200 logical px** (모바일 중앙).

```
┌────────────────────────────┐
│ ░░ 잔디 타일 (16×16 repeat) │
│ ░░░░░░░░░░░░░░░░░░░░░░░░░ │
│ ░░░░░░ [나무 스프라이트] ░░ │
│ ░░░░░░░░░░░░░░░░░░░░░░░░░ │
│ ═══ 흙 길 (하단 16px) ═══ │
└────────────────────────────┘
```

- **잔디:** `#7CB86A` / `#9DCE8E` 2색 체커
- **흙 길:** 하단 1타일 — 2차 정원 진입점 암시
- **꽃:** 좌우 1~2개 16×16 (비활성, 채도 낮음) — 「앞으로 꾸밀 수 있음」

### 3.4 승급 연출 (MVP 최소)

| 트리거 | 연출 | 시간 |
|--------|------|------|
| 단계 상승 | 스프라이트 cross-fade + 8px bounce | 600ms |
| 첫 방문 | 나무 아래 말풍선 「운동할수록 자라요」 | 1회 |
| 3,000 달성 | 벚꽃잎 6개 파티클 (2×2 도트) | 1.2s |

과도한 레벨업 팝업 **금지** — 하단 토스트 「벚꽃나무가 되었어요!」로 충분.

## 4. Progress UI

### 4.1 구조

```
현재 단계  큰 나무
다음 단계  벚꽃나무까지  1,760 성장치 남음

[████████████░░░░░░░░] 41%
1,240 / 3,000
```

### 4.2 스펙

| 요소 | 값 |
|------|-----|
| 바 높이 | 12px |
| 바 radius | 6px |
| 트랙 | `#E8E0D4` (cream-dark) |
| Fill | `growth-accent` → `growth-grass` 그라데이션 (선형) |
| 퍼센트 | `(growth - current_min) / (next_min - current_min)` |
| 최종 단계 | 바 숨김 → 「최고 단계에 도달했어요」 |

### 4.3 카피 규칙

- ✅ 「벚꽃나무까지 **1,760** 성장치 남음」
- ❌ 「레벨 4 달성까지」 (게임 용어)
- ❌ 「1760 EXP」 (영문 약어)

### 4.4 마이크로 인터랙션

- 성장 기록 적립 후 탭 진입 시: Progress fill **+animate 400ms**
- 숫자: `tabular-nums` + 짧은 count-up (선택, 300ms)

## 7. 향후 정원 · 마을 확장 (UI만 암시)

### 7.1 MVP에 넣을 「잠금 힌트」

성장 홈 하단 **점선 카드 1개**:

```
┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
   🏡 정원 · 마을 (준비 중)
   씨앗으로 공간을 꾸밀 수 있어요
└ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

- Tap → 「곧 열릴 예정이에요」 토스트
- 씨앗 잔액이 0이 아니면 「씨앗 N개 모음 중」 보조 문구

### 7.2 레이아웃 예약

| 영역 | MVP | 2차 |
|------|-----|-----|
| 나무 캔버스 높이 | 200px | 240px (정원 미리보기 확장) |
| 캔버스 좌우 | 잔디 only | 16×16 꽃·벤치 placeholder |
| 하단 탭 | 성장 홈·가속·단계 | + 정원 탭 |
| 씨앗 CTA | 전환만 | 「정원 가기」 |

### 7.3 2차 정원 화면 (와이어만)

```
[ 잔디 캔버스 — 그리드 8×6 ]
[ 인벤토리 바: 벤치 · 꽃 · 길 ]
[ 나무는 좌측 고정 — 성장 탭과 동일 스프라이트 ]
```

### 7.4 확장 시 유지할 것

- 도트 16/32 그리드 **유지** (에셋 재사용)
- 성장치 = 영구 / 씨앗 = 소비 **역할 분리 유지**
- CRM 톤(cream 카드) + 도트 캔버스 **혼합** 유지
