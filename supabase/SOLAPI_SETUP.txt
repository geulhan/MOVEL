솔라피 + MotionHub 알림 연동 가이드
================================

[센터별 채널 — 권장 운영 방식]
1) MotionHub 플랫폼: Supabase Secrets에 공용 SOLAPI_API_KEY/SECRET + MESSAGING_ENABLED=true
2) 각 센터 관리자: 관리자 → 메시지 발송 → 「알림톡·문자 채널 설정」
   - 카카오 pfId, 발신번호, 템플릿 ID (센터별)
   - 「이 센터 메시지 발송 사용」 체크
3) 센터별 솔라피 계정이 따로 있으면 「MotionHub 공용 API 키 사용」 해제 후 전용 키 입력

DB: migration_064_center_messaging_config.sql 실행 필수

[검수 전에 할 일]
1) Supabase SQL 실행 (아직 안 했다면 순서대로)
   - migration_016_notifications.sql
   - migration_017_member_self_register.sql
   - migration_018_admin_reset_member_password.sql
   - migration_019_pre_solapi_fixes.sql

2) Edge Function 배포 + Secrets (MESSAGING_ENABLED=false 로 시작)
   NOTIFICATION_INTERNAL_SECRET, SITE_URL, SOLAPI_API_KEY/SECRET, SOLAPI_PF_ID, SOLAPI_FROM_NUMBER

3) Vercel: VITE_NOTIFICATION_TRIGGER_KEY = NOTIFICATION_INTERNAL_SECRET 와 동일

4) 관리자 → 알림 발송 에서 skipped 로그 확인 (실발송 없이 연동 테스트)

5) 솔라피 템플릿 심사 대기 중에도 앱 기능은 위 SQL까지 적용하면 사용 가능


1) 솔라피 가입
   https://solapi.com

2) 카카오 비즈니스 채널 연동
   - 솔라피 콘솔 → 카카오 채널 연동
   - pfId(프로필 ID) 메모

3) 알림톡 템플릿 등록 및 심사 (변수명은 아래와 동일하게, 센터마다 별도 등록)
   [환영] welcome
     #{name}님 #{centerName} 가입을 환영합니다.
     회원 포털: #{portalUrl}
     초기 비밀번호는 휴대폰 뒤 4자리입니다.

   [결제] payment_done
     #{name}님 #{centerName} — #{amount} 결제가 완료되었습니다. (PT #{sessions}회)
     회원 포털: #{portalUrl}

   [갱신] renewal
     #{name}님 #{centerName} 회원권 만료가 #{daysLeft}일 남았습니다. (만료일 #{expiresAt})
     잔여 PT #{remainingSessions}회 · #{portalUrl}

   [PT 리마인더] pt_reminder
     #{name}님 #{centerName} PT 수업이 내일 예정되어 있습니다.
     일시: #{scheduledAt}
     담당: #{trainerName}
     회원 포털: #{portalUrl}

4) 문자 발신번호 등록 (알림톡 실패 시 대체발송용)

5) Supabase SQL Editor에서 실행
   supabase/migration_016_notifications.sql

6) Edge Function 배포 (Supabase CLI)
   supabase login
   supabase link --project-ref YOUR_PROJECT_REF
   supabase secrets set NOTIFICATION_INTERNAL_SECRET=랜덤문자열
   supabase secrets set MESSAGING_ENABLED=false
   supabase secrets set SITE_URL=https://movel.vercel.app
   supabase secrets set SOLAPI_API_KEY=...
   supabase secrets set SOLAPI_API_SECRET=...
   supabase secrets set SOLAPI_PF_ID=...
   supabase secrets set SOLAPI_FROM_NUMBER=...
   supabase secrets set SOLAPI_TEMPLATE_WELCOME=...
   supabase secrets set SOLAPI_TEMPLATE_PAYMENT=...
   supabase secrets set SOLAPI_TEMPLATE_RENEWAL=...
   supabase secrets set SOLAPI_TEMPLATE_PT_REMINDER=...
   supabase functions deploy send-notification
   supabase functions deploy renewal-reminders
   supabase functions deploy pt-reminders

7) Vercel 환경 변수
   VITE_NOTIFICATION_TRIGGER_KEY = NOTIFICATION_INTERNAL_SECRET 와 동일

8) 솔라피 키 입력 후 실발송 켜기
   supabase secrets set MESSAGING_ENABLED=true

9) 자동 실행 Cron (Supabase Dashboard → Edge Functions → Cron)
   [갱신] renewal-reminders — 0 0 * * * (UTC 00:00 = KST 09:00)
   [PT D-1] pt-reminders — 0 * * * * (매시 정각, 수업 24시간 전 ±1시간 대상)
   수동 테스트: 관리자 → 메시지 발송 → 발송 이력 상단 버튼

10) SQL (아직이면)
   migration_022_pt_reminder_dedup.sql
